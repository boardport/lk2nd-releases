# 📦 BoardPort — Релизы lk2nd

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)
[![Project: BoardPort](https://img.shields.io/badge/Project-BoardPort-green.svg)](https://github.com/boardport)
[![Storage: GitHub Releases](https://img.shields.io/badge/Storage-GitHub%20Releases-blueviolet.svg)](https://github.com/boardport/lk2nd-releases/releases)

Централизованный архив и хаб дистрибуции скомпилированных релизов загрузчиков `lk2nd` и `lk1st`,
аппаратных сборок и зеркал апстрима.

Репозиторий входит в экосистему **[BoardPort](https://github.com/boardport)** и предоставляет верифицированные,
воспроизводимые и чистые бинарные релизы загрузчиков для одноплатных компьютеров, 4G/LTE USB-модемов и мобильных устройств.

> 🤖 **Примечание для AI-ассистентов:** Автономные агенты и LLM-ассистенты обязаны ознакомиться с правилами проекта
> в файле [AGENTS_RU.md](./AGENTS_RU.md) перед началом работы в этом репозитории.

---

## 🎯 О проекте

Главная миссия **lk2nd Releases** — предоставление чистого и изолированного канала дистрибуции бинарных образов загрузчиков:

1. **Сборки таргетов BoardPort:** Аппаратно-адаптированные образы загрузчика, собранные оркестратором
   **[lk2nd-builder](https://github.com/boardport/lk2nd-builder)** с интеграцией внешнего оверлея для платформ Qualcomm MSM
   (модемы MSM8916, UFI001C, UFI103S, QRCT и отладочные платы).
2. **Зеркало релизов апстрима:** Долгосрочный архив официальных релизов
   **[msm8916-mainline/lk2nd](https://github.com/msm8916-mainline/lk2nd)** для гарантированной доступности.
3. **Изолированная архитектура:** Хранение бинарных релизов в отдельном репозитории предотвращает засорение тегами
   сборочных проектов и дерева исходных кодов.

## 🏛️ Модель хранения и релизов

Для поддержания чистоты Git-репозитория:

- **В Git хранятся только метаданные:** Репозиторий отслеживает документацию, индексы релизов и CI-воркфлоу.
- **Артефакты в GitHub Releases:** Все бинарные архивы публикуются исключительно в
  **[GitHub Releases](https://github.com/boardport/lk2nd-releases/releases)**.
- **Чистые дистрибутивные пакеты:** Каждый релиз содержит:
  - Архивы `<release>.tar.gz` и `<release>.zip` с оригинальными бинарными файлами
    (`lk2nd.img`, `lk1st.mbn`, `emmc_appsboot.mbn`, `qcdt.img`, `lk.bin`, `lk1st.bin`).
  - Индивидуальные файлы контрольных сумм `<release>.tar.gz.sha256` и `<release>.zip.sha256`.
  - Сводный файл проверки контрольных сумм `SHA256SUMS`.
  - Двуязычные заметки к релизу (`[RU]` / `[EN]`) с инструкциями по установке.

## 🏷️ Соглашения об именовании тегов

Релизы структурируются по префиксам:

| Категория релиза | Шаблон тега | Пример тега | Описание |
| :--- | :--- | :--- | :--- |
| **Таргет BoardPort** | `boardport-<soc>-<version>` | `boardport-msm8916-23.1` | Кастомная сборка с аппаратным оверлеем BoardPort |
| **Зеркало апстрима** | `upstream-<soc>-<version>` | `upstream-msm8916-23.1` | Архивное зеркало официальной сборки lk2nd под конкретный SoC |

## ⚡ Руководство по fastboot

После скачивания и распаковки архива релиза:

### 1. Тестовая загрузка без прошивки (вторичный lk2nd)

Временная загрузка в lk2nd для проверки дисплея, клавиш и вывода консоли:

```bash
fastboot boot lk2nd.img
```

### 2. Постоянная прошивка вторичного загрузчика (раздел boot)

Запись lk2nd в качестве основного загрузочного ядра:

```bash
fastboot flash boot lk2nd.img
```

### 3. Прошивка первичного загрузчика (lk1st в раздел aboot)

Для аварийного восстановления или замены первичного загрузчика:

```bash
fastboot flash aboot lk1st.mbn
```

### 4. Проверка контрольных сумм

```bash
# Проверка индивидуального архива:
sha256sum -c <archive>.tar.gz.sha256

# Либо проверка всего сводного манифеста:
sha256sum -c SHA256SUMS
```
