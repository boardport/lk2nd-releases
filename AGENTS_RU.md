# Паспорт проекта и регламент для AI-агентов: lk2nd Releases

> **Проект:** BoardPort — lk2nd Releases  
> **Организация:** [BoardPort](https://github.com/boardport) | **Репозиторий:** `boardport/lk2nd-releases`  
> **Миссия:** Централизованный хаб дистрибуции и архив релизов загрузчиков lk2nd/lk1st  
> **Целевая экосистема:** Встраиваемые платформы, 4G/LTE-модемы и мобильные устройства | **Лицензия:** [MIT](./LICENSE)  

---

## 1. Организация контекста AI

Корневые файлы [`AGENTS.md`](./AGENTS.md) и [`AGENTS_RU.md`](./AGENTS_RU.md) определяют базовый регламент для всех AI-ассистентов:

- **Специализированные каталоги (`.(gemini|claude|cursor|continue|qwen|etc)/`):** Индивидуальный контекст конкретных AI-ассистентов
  (промпты, отчеты, дампы сессий). Изолированы и исключены из Git-индексации (`.gitignore`).
- **Файл `.aiignore`:** Определяет ресурсы, исключенные из фонового сканирования
  (бинарные файлы прошивок, дампы разделов, образы загрузчиков, архивы).

---

## 2. Архитектура и модель хранения релизов

- **В Git хранятся только метаданные:** Репозиторий Git содержит документацию, реестры релизов, манифесты и скрипты.
- **Бинарные артефакты в GitHub Releases:** Все архивы (`.tar.gz`, `.zip`) и контрольные суммы (`SHA256SUMS`) размещаются строго
  в **[GitHub Releases](https://github.com/boardport/lk2nd-releases/releases)**.
- **Чистота Git-индексации:** Бинарные файлы (`*.bin`, `*.img`, `*.mbn`), дампы (`dumps/`), временные каталоги (`tmp/`)
  категорически запрещено коммитить в Git.
- **Интеграция со сборочным репозиторием:** Бинарные образы собираются и публикуются из `boardport/lk2nd-builder` в данный репозиторий.

---

## 3. Стандарты документации Markdown

- **Правила форматирования:** Синтаксис регламентируется `.editorconfig` и `.markdownlint-cli2.jsonc`.
- **Обязательная проверка:** Выполняйте `npx markdownlint-cli2 "**/*.md"` (результат: `0 issues in 0 files`).
- **Зеркальная двуязычность:** Вся публичная документация ведется параллельно (`*.md` на английском и `*_RU.md` на русском).

---

## 4. Стандарты Git и GitHub (`.github/`)

- Организационные политики, шаблоны задач и PR располагаются в [`.github/`](./.github/).
- Сообщения коммитов следуют стандарту Conventional Commits (например, `feat:`, `fix:`, `docs:`, `chore:`).
- **Правило фиксации коммитов:** Создание коммитов допускается **только по прямому подтверждению пользователя**.
